SwissNFC/RFID — Flipper Zero lab audit toolkit
==============================================

Nine companion apps for AUTHORIZED RFID/NFC security work. Built against MOMENTUM
firmware (API 87.1). Rebuild from the source/ folders for other firmware.

  em4100_stepper/    "RFID Stepper"     LF 125kHz  read/step/emulate/sweep; HID card# sweep
  nfc_uid_stepper/   "NFC UID Stepper"  HF 13.56   UID read/step/emulate/sweep + verdict
  reader_audit/      "Reader Audit"     HF         UID-only vs crypto; writes-back; report
  dualtech_scan/     "Card ID"          LF+HF      identify LF+HF tech + verdict + combo
  card_audit/        "Card Audit"       LF+HF      AUTHORIZED: read/verify/report to SD
  blank_validator/   "Blank Validator"  LF+HF      is this blank writeable? which magic type?
  clone_writer/      "Clone Writer"     HF         write a MFC dump onto a magic blank
  cloner_sniff/      "Cloner Sniffer"   HF         log a writer/cloner's frames + nonces
  card_emu/          "Card Emulator"    HF         the Flipper BECOMES a saved card
  research/vulnerability-catalog.md   card-side vuln catalog + detection signatures
  research/clone-and-vuln-reference.html  the "can I clone this card?" (dd) model + vuln matrix
  research/          reader-side security research corpus (sourced)

--------------------------------------------------------------------------------
INSTALL (no build)
  Create a folder  apps/swissnfcrfid  on the Flipper SD card and copy all eleven
  .fap files into it (qFlipper desktop or the mobile app). They then appear
  together under  Apps -> swissnfcrfid  on the device.

--------------------------------------------------------------------------------
RFID Stepper (LF)  &  NFC UID Stepper (HF)
  Read a card (or Load a saved file / Manual entry), step the ID/UID, and emulate
  or AUTO-sweep. Shows a security VERDICT (skull for vulnerable):
    LF -> every decodable card = CLONE (no secure 125kHz exists)
    HF -> BROKEN (Crypto1 / orig DESFire) / SECURE (DESFire EV1+) / CLONE (UL/NTAG)
          / UNK ; DESFire generation via GetVersion ; RND = random-UID (privacy).
  Edit controls:
    Left/Right pick field (ID / Pos / step / delay / dir)
    Up/Down    change field
    OK         start sweep -> pause -> resume
    OK (hold)  quick-save current card to file (shows "Saved ..." confirmation)
    Back       stop the sweep / back to menu
  TRUNCATION TEST: set field "Pos" to a byte (B0..Bn) to step only that byte;
  sweep it and watch the door -> if access is unchanged, the reader truncates it.
  HID ACCEPTANCE-ORACLE (NEW): read an HID Prox (H10301) card and "Pos" gains a
  "Cn" value -> Up/Down sweeps the 16-bit CARD NUMBER while holding the facility
  code, and the protocol recomputes Wiegand parity, so every step is a valid
  credential. Auto-selected when an HID card is read.

Reader Audit (HF)
  Menu: Read card + audit (read a valid card, then emulate it) / Audit (default UID).
  Classifies what the reader does after selecting the card:
    UID-ONLY!  = read the UID then halted                        (INSECURE)
    CRYPTO     = sent RATS / auth (ISO14443-4 / Mifare)          (uses card crypto)
    READS DATA = read data pages (0x30)
    +WR        = the reader WROTE back (0xA0/0xA2) -> anti-passback / counter
  Saves each audit to /ext/reader_audit.txt.
  NOTE: to collect mfkey32 nonces from a reader, use Cloner Sniffer "Emul MFC"
  (writes /ext/nfc/.mfkey32.log) + the MFKey app.

Card ID (LF+HF)
  Hold ONE card, press OK: reads it on 125kHz LF then 13.56MHz HF (full NFC
  scanner), NAMES the technology, and gives a security VERDICT for the HF tech
  (BROKEN Crypto1 / CLONE / SECURE* AES / 15693 / PAYMENT / etc.). Flags
  DUAL-TECH combo cards (weak OR-logic access). If LF is present but no standard
  HF answers, hints "iCLASS? use Picopass app" (iClass isn't exposed to apps).

Card Audit (LF+HF)  -- AUTHORIZED USE ONLY
  Confirm the authorization gate, then:
    Audit HF card   -> read + classify + ACTIVELY verify:
        Mifare Classic: 37-key default-key dictionary per sector; on full match it
                        saves a clone .nfc to /ext/nfc and reports DUMP N/M sectors.
                        Also flags STATIC KEY (same key all sectors = clone-once/
                        open-all) and FUDAN backdoor silicon (auths with the public
                        A396EFA4E24F key -> all keys recoverable, eprint 2024/1275).
        DESFire:        GetVersion generation + unauth config -> BROKEN / WEAK-CFG /
                        SECURE.
        NTAG/UL:        reads a user page w/o auth as proof (or UNK if protected).
    Audit LF card   -> read = confirmed cloneable.
    Load .nfc (offline) -> classify a saved dump; checks stored keys vs the dict.
    View reports    -> browse/scroll the timestamped reports on the SD card.
  Reports go to /ext/swissnfcrfid_reports/ and carry an authorization notice.
  Verifies weakness with REAL data; it does NOT break AES (DESFire EV1+).

Blank Validator (LF+HF)
  Non-destructive writeability test: read original -> write test value -> read
  back -> restore. Menu: Auto (LF then HF) / Test LF only / Test HF only.
    LF -> T5577/EM4305 (writes a test EM4100 ID).
    HF -> NTAG/UL (user page), Mifare Classic magic identifier:
        gen1a backdoor probe            -> "HF gen1a"
        gen2/CUID raw block-0 write      -> "HF CUID/gen2" (also GDM backdoor auth)
        gen3 90F0 probe                  -> "HF gen3"  (replaces the old Gen3 Probe app)
        else data-block write            -> memory writeable, not magic
  NOTE: HF tests MEMORY writeability + magic type; it does not perform a magic
  UID clone (use NFC Magic / Clone Writer).

Clone Writer (HF)  -- AUTHORIZED USE ONLY, OVERWRITES the target
  Load a Mifare Classic dump (Read source card OR From saved .nfc) and write it
  onto a MAGIC blank (gen2/CUID). Each block is retried across key A / key B / the
  dump's own keys. Block 0 (UID) writes only on gen2/CUID targets. gen1a UID write
  is NOT done here (use NFC Magic).

Cloner Sniffer (HF)  -- AUTHORIZED RESEARCH ONLY
  Card-emulation trap to reverse-engineer a writer/cloner. Modes:
    Sniff: passive / ACK knocks / Raw (no anticol) -> log every raw frame.
    Emul MFC (.nfc) -> full Mifare Classic emulation from a saved dump: the cloner
      completes auth against the Flipper, its writes land in emulated memory (diffed
      afterward), and every auth nonce is captured to /ext/nfc/.mfkey32.log for MFKey.
  Not a wire sniffer; it is a trap the writer talks to.

Card Emulator (HF)  -- the one-device wallet
  Pick a saved .nfc and the Flipper BECOMES that card (full Mifare Classic + keys,
  ISO14443-A UID, or Ultralight). For cards you can't clone onto a blank, this is
  the answer: the Flipper replaces the card. Shows a live "reads" counter.

--------------------------------------------------------------------------------
REBUILD (any app)
  pip install ufbt
  ufbt update --index-url=https://up.momentum-fw.dev/firmware/directory.json --channel=release
  cd <app>/source && ufbt          # -> dist/<app>.fap
  ufbt launch                      # build + install + run on a connected Flipper

Use only on cards / readers / systems you own or are authorized to test.

--------------------------------------------------------------------------------
COMPANION TOOLS (recommended to install alongside this toolkit)
--------------------------------------------------------------------------------
These official/third-party tools fill gaps this toolkit intentionally leaves.

  MFKey (flipperzero-good-faps/mfkey)  -- INSTALL, highest value
    On-device Mifare Classic key RECOVERY (mfkey32 + static-nested). Recovers
    NON-default keys, which Card Audit's default-key dictionary cannot.
    Workflow:  stock NFC app "Detect Reader"/"Extract MF Keys"  -> collects a
    reader's auth nonces to /ext/nfc/.mfkey32.log  ->  MFKey cracks the key  ->
    Card Audit / Clone Writer use the recovered key to dump & clone.
    NOTE: Cloner Sniffer's "Emul MFC" mode ALSO writes /ext/nfc/.mfkey32.log
    (pairs of captured nonces) so MFKey can crack a cloner/reader's standard key.

  NFC Magic (flipperzero-good-faps/nfc_magic)  -- INSTALL
    Writes MAGIC cards: Gen1A/Gen1B, Gen2 (DirectWrite/CUID/FUID/UFUID),
    Gen4 GTU (with password). The proper tool for UID cloning onto magic blanks.
    Does NOT support Gen3 (APDU) or Gen4 GDM (Blank Validator flags Gen3).

  Picopass (built-in / app catalog)  -- for iCLASS/HID 13.56
    iCLASS/Picopass is NOT in the Flipper's shared NFC library and cannot be read
    by an external app. The Picopass app carries its own stack: read iClass Legacy,
    dump PACS, loclass online nonce collection, emulate, write magic iClass.
    Card ID points you here when a card is likely iClass.

  NFCMiTM (github.com/a66at/NFCMiTM)  -- optional, hardware
    True inline relay MITM: Raspberry Pi + two PN532 readers, logs the full
    reader<->card conversation (APDU parser). Best for ISO14443-4 / APDU systems
    (DESFire, access, payment). PN532 can't relay Mifare Crypto1 cleanly.

  Proxmark3 RDV4 (/ Proxmark5, pre-order ~Oct 2026)  -- the heavy lifter
    Full iClass loclass offline solve, DESFire, deep protocol work. Proxmark5 is
    crowdfunded with native Flipper Zero integration (USB-C + optional BLE add-on);
    until it ships, the Flipper field-collects and a PC/Proxmark3 does the solve.

TYPICAL LAB CHAINS
  Unknown MFC with custom keys:
    stock Detect Reader -> MFKey (crack) -> Card Audit (dump) -> Clone Writer
  Clone a UID onto a magic blank:
    Card Audit (dump source) -> Blank Validator (id the blank type) ->
    NFC Magic (gen1a/2/4-GTU)  OR  Clone Writer (gen2 memory)  OR
    Blank Validator flags Gen3 APDU targets
  Be the card (no clone needed):
    Card Audit (dump) -> Card Emulator (Flipper becomes it)
  Audit a reader:
    Reader Audit (detect band + UID-only/crypto/writes-back) ;
    RFID Stepper "Cn" (HID card# acceptance-oracle) ;
    Cloner Sniffer "Emul MFC" -> MFKey (recover the reader's key)
  Reverse a proprietary cloner:
    Cloner Sniffer "Emul MFC" (nonces -> .mfkey32.log) -> MFKey ;
    or NFCMiTM for APDU-level relay capture.
