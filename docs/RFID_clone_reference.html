The dd model

On a computer, dd clones a disk because the disk is passive storage — the secret lives in copyable software, not the medium. RFID splits along exactly that line.

The rule. A raw dump-and-write (RFID's dd) works when the medium is storage and the secret is copyable. It fails the moment the key lives in unreadable silicon and the card proves knowledge by computing a challenge-response — the RF equivalent of a TPM-bound disk.
